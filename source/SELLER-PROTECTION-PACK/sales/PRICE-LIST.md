| Package | Indicative price | Include only if actually deliverable | Excludes by default |
|---|---:|---|---|
| ZIP only | €100 | One release ZIP and SHA-256 | Setup, deployment, support beyond any written promise, legal review |
| ZIP + setup guide | €300 | ZIP plus written guide matched to the exact release | Domain, hosting, database/service fees, integrations |
| ZIP + setup + training | €500 | ZIP, guide, and [number] hours of remote training on [date/range] | Ongoing support, custom features, third-party charges |
| Payment integration | €1,500+ | Only after gateway, country, API, fees, refunds, webhooks and acceptance tests are scoped | Provider fees, legal/tax advice, unquoted future changes |
| Full package | €5,000+ | Only a written statement of work defining architecture, UX, deployment, testing, support and acceptance | Anything not explicitly listed; third-party subscriptions |

These are pricing suggestions, not a validated market price or a binding quote. State whether VAT/tax is included, invoice details, delivery, support hours and acceptance criteria. Do not promise a payment/courier integration before selecting a provider and verifying API access, test credentials, compliance and production testing. Never sell all work for a flat €500 if the scope includes substantial custom development.
