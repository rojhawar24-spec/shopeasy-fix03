# FIX6 — Windows: چۆن تاقیکردنەوەکان بکەیتەوە

ئەم وەشانە ٧ هەڵەی لۆگی ناردووت چارەسەر دەکات کە ٥یان بەهۆی Windows file path، ١یان تاقیکردنەوەی کۆنی داشکاندن، و ١یان وێنەی PNG ـی ناتەواو بوو.

1. Node.js 24.22.2 یان نوێتر (لە شاخەی 24) دابمەزرێنە.
2. ZIP ـەکە extract بکە بۆ فۆڵدەری نوێ؛ مەیخەرە سەر فۆڵدەری داتای کڕیارەکان.
3. لە فۆڵدەری project ـەکە PowerShell بکەرەوە.
4. فەرمانەکان بە ڕیز بنووسە:

```powershell
node -v
npm ci
npm test
npm run audit
npm run test:integration
```

ئەگەر هەموو تاقیکردنەوەکان سەرکەوتن، پاشان پێویستە لە Staging دا Login/MFA، Dashboard، وێنە، قەبارە، کۆگا، Checkout، پارەدان، Backup، یاسا و مۆڵەتی بازرگانی بە کردار تاقی بکرێنەوە.

**ئاگاداری:** تەنانەت 100% سەرکەوتنی test بەڵگەی 100% بێ هەڵەبوونی وێبسایت نییە. فایلە نهێنییەکانی `.env`، داتابەیس و uploads پارێزە. ئەم فایلە بەڵگەی مۆڵەتی فرۆشتنی نەرمەکاڵا نییە.
